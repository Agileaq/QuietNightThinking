# 《静夜思》Three.js 视听网页设计规格说明书 (Design Spec)

- **项目名称**：QuietNightThinking（李白《静夜思》Three.js 3D 视听诗歌剧场）
- **日期**：2026-10-18
- **定位**：基于 Three.js 实时三维渲染、结合预生成真实现场感诗词朗诵音频与 Web Audio API 程序化古琴/秋夜环境音的网页端可交互“3D 诗歌视频”。

---

## 1. 背景与目标 (Purpose & Success Criteria)

### 1.1 目标
将唐代诗人李白的《静夜思》（“床前明月光，疑是地上霜。举头望明月，低头思故乡。”）转化为一部可在浏览器中像视频一样播放、拖拽进度、跳转章节、同时保留 3D 空间交互（播放时鼠标视差、暂停时自由 360° 环视）的视听作品。

### 1.2 成功标准
1. **视频化时间轴体验**：具备完整的 32 秒时间轴与 6 个分镜章节（序幕、四句诗对应四幕、尾声），支持播放、暂停、重播、进度条任意拖拽（Scrubbing）、章节锚点一键跳转、全屏切换。
2. **有声有色（朗诵 + 古琴 + 环境音）**：
   - 内置高质量预生成中文《静夜思》朗诵音频（`public/audio/recitation.mp3`），与时间轴各幕精确同步；同时内置 Web Speech API 兜底保障。
   - 基于 Web Audio API 实时程序化合成五声音阶古琴拨弦/泛音背景乐，以及秋夜微风与蟋蟀虫鸣环境音。
3. **写意唐风 3D 视觉与分镜运镜**：
   - 包含室内（唐风木质床榻、雕花直棂窗、残烛案几）与室外庭院（青石板地、水缸、假山苍松、远山剪影、星空与体积感明月）的联动场景。
   - 包含程序化构建的写意李白 3D 形象（圆领长袍、发髻高冠、衣袖微动），在第三幕完成“举头望明月”仰首动作，在第四幕完成“低头思故乡”垂首动作。
   - 具备两大核心视觉特效：第二幕地面月光化作银白冰晶蔓延的“疑是地上霜”Shader/粒子特效，以及第四幕水面与地面浮现温暖金色故乡山水幻影的“低头思故乡”光影特效。

## 3. 时间轴与分镜详细设计 (`TimelineData.js`)

总时长固定为 **32.0 秒**，所有视觉与声音状态均为当前时间 `t ∈ [0, 32]` 的确定性函数：

| 章节 ID | 名称 | 时间范围 (秒) | 朗诵内容與时间窗口 | 相机机位与运动轨迹 (`pos` -> `lookAt`) | 角色与特效关键状态 (`state(t)`) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `intro` | **序幕：静夜** | `0.0 - 5.0` | `1.2s - 4.2s`: “静夜思。唐，李白。” | 从庭院高处远眺明月与苍松 `(-4.5, 4.2, 8.5)` 缓慢推向半掩的唐风雕花木窗 `(-1.2, 2.3, 4.2)` | 烛火微摇，月光束透过窗棂，地面霜华强度 `frost=0.0`，李白平视窗外 `headPitch=0` |
| `verse1` | **床前明月光** | `5.0 - 11.0` | `5.8s - 9.8s`: “床前，明月光，” | 镜头穿入室内床榻前侧 `(1.8, 1.9, 2.4)` 平滑横移至 `(0.6, 1.6, 2.0)`，聚焦木榻与洒落地面的银白月光光束 | 体积月光强度提升至 `1.0`，光尘粒子在月光锥内缓缓浮动，李白静立窗前 |
| `verse2` | **疑是地上霜** | `11.0 - 17.0` | `11.8s - 15.8s`: “疑是，地上霜。” | 镜头俯身贴近青石地面 `(0.2, 0.75, 2.8)` 缓步滑向庭院台阶 `(-0.8, 0.9, 3.6)`，平视地面月华 | `frost` 从 `0.0` 平滑增长至 `1.0`：地面自定义 Shader 呈现六角冰晶纹理与银白寒霜粒子升腾 |
| `verse3` | **举头望明月** | `17.0 - 23.5` | `17.8s - 22.0s`: “举头，望明月，” | 镜头移至李白身侧 `(-1.1, 1.75, 1.8)`，随李白抬头动作同步向上仰摇，看向高空满月 `(0.0, 11.5, -18.0)` | 李白头部仰角 `headPitch` 从 `0` 平滑升至 `+0.58 rad (+33°)`，满月大气光晕脉冲扩张 |
| `verse4` | **低头思故乡** | `23.5 - 29.0` | `24.2s - 28.2s`: “低头，思故乡。” | 镜头随李白垂首动作从仰视转为俯视庭院水缸与地面霜影 `(-1.2, 1.8, 2.2)` -> `LookAt(-1.2, 0.3, -0.8)` | 李白头部俯角 `headPitch` 平滑降至 `-0.42 rad (-24°)`；`homelandGlow` 升至 `1.0`，浮现暖金色故乡远山与水面涟漪粒子 |
| `outro` | **尾声：余韵** | `29.0 - 32.0` | 古琴泛音尾韵 | 镜头缓缓拉远至庭院全景 `(-5.5, 4.0, 9.5)`，将室内木窗、庭院苍松、李白身影与高空明月尽收眼底 | 全诗四列竖排书法并列浮现，定格于诗意画卷，播放结束时显示重播引导 |

## 4. 核心子系统设计

### 4.1 混合相机控制器 (`CameraController.js`)
- **播放态（Cinematic + Parallax）**：
  - 根据 `TimelineData.getCameraPose(t)` 计算当前时刻的基准位置 `basePos` 和观察目标 `baseTarget`（内部使用三次平滑插值 `smoothstep` 消除关键帧折角）。
  - 叠加鼠标归一化坐标 `(mouseX, mouseY)` 带来的阻尼微偏移（位置偏移幅度 `±0.25m`，视角偏移 `±0.15m`），让用户在观看视频时依然能直接感受到画面是实时渲染的 3D 空间而非死板的平面视频。
- **暂停态（Free Orbit Inspection）**：
  - 当用户点击暂停时，启用 Three.js `OrbitControls`，以当前 `lookAt` 点为旋转中心，允许用户拖拽鼠标 360° 自由观察唐风房间、李白模型与庭院明月。
  - 当用户再次点击播放或拖动进度条时，相机在 `0.4s` 内平滑过渡回时间轴分镜轨。

### 4.2 3D 场景与视觉特效 (`TangCourtyard.js`, `PoetCharacter.js`, `VisualEffects.js`)
- **色彩与光影基调**：
  - 主色调采用唐夜青黛色（`#070b16` ~ `#0f1a2e`）、月华银白（`#d8e8ff`）与室内烛火/故乡思念暖金（`#ffaa44`）形成冷暖映衬。
  - 启用 `EffectComposer` + `RenderPass` + `UnrealBloomPass`，让明月、地面银霜微粒与故乡金色涟漪散发柔和的电影级辉光。
- **“地上霜”自定义 Shader**：
  - 在地面受光区域放置平面网格，使用基于径向距离、Simplex 噪声与星芒闪烁函数的 Fragment Shader，通过 `uFrostProgress` (`0.0 ~ 1.0`) 控制银霜从窗前月光落点向四周结晶蔓延的动态过程。
- **“思故乡”金色粒子山水幻影**：
  - 在第四幕通过粒子点云构建微缩的金色远山与归舟轮廓，配合水面/地面同心圆波纹 Ring 扩散，表达“思故乡”的内心投射。

### 4.3 声音引擎 (`AudioEngine.js`)
- **预生成朗诵音轨 (`public/audio/recitation.mp3`)**：
  - 使用构建脚本在本地生成分段配音（引子 + 四句古诗），按照第 3 节时间表精确混音合成为一条 32.0 秒的立体声 MP3 音轨，保证任何时刻 `seek(t)` 时音频 `currentTime = t` 都能与画面口型/字幕严丝合缝。
- **Web Audio 程序化古琴与夜色环境音**：
  - **古琴音色合成**：采用五声音阶羽调式（`A2, C3, D3, E3, G3, A3, C4, D4, E4`），结合基波 + 偶次/奇次泛音振荡器组与指数衰减低通滤波器模拟古琴拨弦与泛音（Harmonics），根据预设乐谱时间表触发。
  - **秋夜环境音**：利用粉红噪声经带通滤波模拟秋夜微风，配合高频正弦波调制脉冲模拟远处清脆的秋虫鸣叫。

### 4.4 视频播放器 UI (`PlayerUI.js`)
- **字幕展示**：屏幕右上/右侧区域采用竖排从右向左的古典诗词排版，支持单句特写（随朗诵进度逐字显现并带微光）与尾声全诗并列展示。
- **控制栏功能**：
  - 播放/暂停切换（支持空格键快捷键）；
  - 可拖拽与点击跳转的时间轴进度条，进度条上方带 6 个分镜章节圆点与中文标签，点击任意章节标签直接跳转到该幕起始时间；
  - 实时时间显示（`MM:SS / 00:32`）、静音/音量调节、全屏切换；
  - 状态提示角标（显示当前是“电影运镜模式”还是“暂停自由环视模式”）。

## 5. 错误处理与测试计划 (Error Handling & Testing)

1. **浏览器自动播放限制处理**：首次进入页面展示古典画卷封面与「开始播放」按钮，用户点击后在同一个手势事件内解锁 `AudioContext.resume()` 并启动 `<audio>` 播放。
2. **音频加载容错**：如果 `recitation.mp3` 因极端网络或环境原因未能加载，`TimelineEngine` 仍以 `performance.now()` 高精度时钟独立推进 32 秒视频画面，并自动启用 `window.speechSynthesis` 中文语音按时间点触发朗诵，绝不阻塞播放。
3. **自动化测试 (`tests/timeline.test.js`)**：
   - 使用 `vitest` 编写针对 `TimelineData` 和 `TimelineEngine` 的单元测试，验证：
     - 0~32 秒内各时间点对应的章节 ID 与字幕状态准确性；
     - 第三幕（举头）与第四幕（低头）的李白头部俯仰角度符号与范围（举头 > 0，低头 < 0）；
     - 第二幕（地上霜）与第四幕（思故乡）特效强度随时间单调变化及边界夹紧（`[0, 1]`）；
     - `TimelineEngine` 的播放、暂停、拖拽跳转 (`seek`) 与播放完成停机逻辑。
